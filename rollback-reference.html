입력부터 롤백·표시까지

두 세계가 실제 WebRTC로 연결됩니다. 걷기·대시·발사체를 보면서 판정 TPS와 표시 프레임이 어떻게 분리되는지 비교하세요.

입력 60Hz · 표시 RAF · baseHz 120의 정수 분주. TPS는 실행 중 잠깁니다.

TPS 비교: 중지 → TPS 선택 → 새 방 시작. 온라인에서는 두 참가자 모두 나가고 같은 TPS·방 번호로 다시 연결하세요. 다른 TPS는 다른 방 namespace/handshake 계약이므로 기존 방을 바꾸지 않습니다.

여기서 확인할 연결

← → 는 A 걷기, A/D는 B 걷기. Space는 A 대시, F는 A 발사입니다. 버튼도 사용할 수 있습니다. 대시 버튼을 놓아도 흰 action 원이 끝날 때까지 로컬 preview가 유지됩니다.
